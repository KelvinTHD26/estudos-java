# Estudos de Java

Exercícios feitos durante a disciplina de Lógica de Programação/Java na Engenharia de Software (UniFil). Cada pasta representa uma atividade da faculdade, com foco progressivo em arrays, matrizes, sub-rotinas (métodos), manipulação de strings e menus interativos.

## Conteúdo

- **Atividades05** — Introdução a arrays: temperaturas da semana, lista de nomes, controle de estoque simples.
- **Atividade06** — Sub-rotinas (métodos): sistema de análise de notas de turma e controle de vendas semanais.
- **Atividade07** — Arrays e matrizes: controle de gastos, presença de alunos (matriz), conversão de temperatura, gols de jogadores (matriz).
- **Atividade08** — Matrizes aplicadas: consumo de energia, vendas por vendedor/semana, notas de alunos com situação (aprovado/reprovado).
- **Atividade09** — Manipulação de strings: validação de nomes, busca de palavra em frase, gerador de nome de usuário.
- **Atividade10** — Sistema de menu interativo (CRUD de estoque com switch/case e do-while).
- **Atividade11** — Matrizes quadradas (3x3 e 4x4): maior/menor valor, soma total, soma da diagonal principal.
- **Atividade12** — Matrizes com múltiplos métodos: vendas por vendedor/semana, cadastro de alunos com busca por nome.
- **extras** — Projetos avulsos: mostra escolar de projetos digitais (arrays + matrizes + busca), algoritmos de divisibilidade/congruência, agenda de contatos, calculadora simples.

## Tecnologias
Java puro (sem frameworks), uso de `Scanner` para entrada de dados, arrays uni e bidimensionais, métodos estáticos, estruturas de repetição e decisão.
