# Estudos de Java

Exercícios em Java feitos por mim nas aulas de programação da graduação em Engenharia de Software (UniFil, Londrina-PR). Cada pasta corresponde a uma atividade da faculdade e os assuntos avançam aos poucos: arrays, matrizes, métodos, strings e um menu interativo.

São programas de console, em andamento. O repositório mostra o meu estudo dos fundamentos da linguagem.

## Conteúdo

| Pasta | O que tem |
|---|---|
| Atividades05 | Introdução a arrays: temperaturas da semana, lista de nomes de alunos e quantidades de produtos em estoque (maior, menor e itens com pouco estoque) |
| Atividade06 | Métodos: análise de notas de uma turma e controle de vendas semanais |
| Atividade07 | Arrays e matrizes: gastos da semana, presença de alunos, conversão de temperatura e gols de jogadores |
| Atividade08 | Matrizes: consumo de energia, vendas por vendedor e semana, notas de alunos com situação (aprovado/reprovado) |
| Atividade09 | Strings: tratamento de nome digitado, busca de palavra em uma frase e geração de nome de usuário |
| Atividade10 | Menu interativo de estoque (cadastrar, listar, procurar, alterar, remover) com `switch/case` e `do-while`, usando arrays |
| Atividade11 | Matrizes 3x3 e 4x4: maior e menor valor, somas, soma por linha e coluna e diagonal principal |
| Atividade12 | Programas divididos em vários métodos: vendas por vendedor e semana, cadastro de alunos com busca por nome |
| extras | Programas avulsos: mostra escolar de projetos digitais (notas de 3 jurados em matriz, média, classificação, busca por palavra e projeto vencedor), 8 algoritmos de divisibilidade e congruência com o operador `%`, agenda de 4 contatos com busca por nome e contagem por DDD, e calculadora simples com `switch` |

## Conceitos praticados

- Entrada de dados com `Scanner`
- Estruturas de decisão e repetição (`if/else`, `for`, `do-while`, `switch`)
- Arrays unidimensionais e bidimensionais
- Métodos estáticos com parâmetros e retorno
- Métodos de `String` (`trim`, `split`, `contains`, `indexOf`, `toUpperCase`)
- Validação simples de entrada (nome vazio, nota fora do intervalo de 0 a 10)
- Operador `%` (resto) em problemas de divisibilidade e congruência

## Como executar

1. Clone o repositório.
2. Abra a pasta no IntelliJ IDEA (ou outra IDE Java). É preciso ter um JDK instalado; o projeto está configurado com o JDK 26.
3. Execute o método `main` da classe que quiser testar.

Os programas pedem os dados pelo terminal.
